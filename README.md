# Sumit Kumar — personal academic website

Source for **https://sumitclimate.github.io**, the homepage of Sumit Kumar, PhD candidate at the
Centre for Atmospheric & Oceanic Sciences (CAOS), Indian Institute of Science, Bengaluru.

Research: radiative forcing, climate feedbacks and forcing efficacy for methane, black carbon and
stratospheric sulfate aerosols, using CESM/CAM5 experiments and the radiative kernel technique.

## Structure

| File | What it is |
|---|---|
| `index.html` | The whole site — a single self-contained page (styles and script inline) |
| `profile.jpg` | Portrait shown in the header and in link previews |
| `Figure8.png`, `Figure.png` | Figures for the methane and black carbon research cards |
| `Figure3.png`, `Figure9.png` | Additional black carbon figures (not currently shown) |
| `Sumit_Kumar_CV.pdf` | CV linked from the "View CV" buttons |

## Updating

- **New paper or status change:** edit the matching `research-card` and `pub-item` blocks in `index.html`.
- **News:** add a `news-item` at the top of the `#news` section.
- **CV:** replace `Sumit_Kumar_CV.pdf`, keeping the same file name.
- **Photo:** replace `profile.jpg` with a square image (about 800 × 800 px).

Changes pushed to `main` go live on GitHub Pages within a minute or two.
